# Jersey Weather Chat

Live weather pages for Jersey, made for the Jersey Weather Chat Facebook community: **[www.jerseyweatherchat.com](https://www.jerseyweatherchat.com)**

Run by volunteers. Forecasts come from computer models and are not official warnings. Jersey Met is the authority: [gov.je/weather](https://www.gov.je/weather).
