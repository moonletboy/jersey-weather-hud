JERSEY WEATHER CHAT · PUSH TEST

Open this page at www.jerseyweatherchat.com/push-test.html in a real browser tab (not inside Facebook). On iPhone it must be opened from the home-screen app. Work down the page in order.

1 · CAN THIS DEVICE DO PUSH?

2 · VAPID KEYS (do this ONCE, on your PC)

These two keys are what lets the GitHub Action prove it’s allowed to message your subscribers. They’re made here in your own browser and never leave it until you copy them. The public key goes on the website; the private key goes ONLY into a GitHub secret. Never paste the private key into chat, Facebook or a file in the repo.

Public key (VAPID_PUBLIC_KEY)
Private key (VAPID_PRIVATE_KEY)

Also needed later: VAPID_SUBJECT = mailto: followed by an email address you own (push services use it to contact you if something goes wrong).

3 · SUBSCRIBE THIS DEVICE WITH THE PUBLIC KEY

PASS here means: permission granted, the service worker (sw.js, jwc-v3) is installed, and the browser issued a push address for this device. The local notification tests that notifications actually appear on this device. The real end-to-end test (a push from GitHub) comes with the Action.
